# Synthetic Public Safety Data

These files contain synthetic data generated for testing the public safety resource allocation scenario. You can import them to quickly reproduce the results from the final report tests.

## Submission Scenarios

1. **Scenario 1**: This scenario evaluated a baseline with one valid participant from each stakeholder group, for a total of five participants.
2. **Scenario 2**: This scenario involved 18 participants and examined disagreement across multiple stakeholder groups under conditions of business influence without full dominance.
3. **Scenario 3**: This scenario involves 29 participants, of which 34.5% belonged to the business/economic stakeholder group, and was designed to assess a business-skewed participation imbalance in which local business owners heavily influenced prioritization toward rapid crime-reduction objectives.


## Usage Guide

1. **Create a Session**: Go to "Manage Sessions" and create a new polling session with the public safety resource allocation scenario.
2. **Configure Session**: Set weighting method (AHP), ranking method (TOPSIS), multi-stakeholder and access rules
3. **Monitor Submissions**: Track submission progress on the "Manage Submissions" page
4. **Import Submissions**: Under the "Manage Submissions" page select the "Import Submissions" tab and import the submission trial set
5. **Process Results**: Run aggregation to calculate weights and final rankings
6. **Export Results**: Export submission analytics and final rankings to Excel
